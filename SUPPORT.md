# Support

## Setup and usage help

Start with the [setup guide](docs/setup.md), then run:

```bash
bowerbird doctor
```

Search existing GitHub issues before opening a new one. If the problem appears
to be a reproducible Bowerbird defect, use the bug report form and include the
sanitized `bowerbird doctor` output, your Python version, operating system, and
the exact failing command.

This is a community-maintained open source project. Support is best-effort; no
response or resolution time is guaranteed.

## Keep private-instance data private

Do not post tokens, secret values, private repository links, raw knowledge-base
content, private account lists, Slack channel IDs, or unredacted workflow logs.
Use placeholders and the smallest synthetic example that reproduces the issue.

Questions about X, GitHub, Slack, or model-provider billing, outages, account
access, and service policy belong with that provider unless Bowerbird is causing
the problem.

## Security reports

Do not open a public support request for a vulnerability. Follow
[SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.
